## 👨‍💻 About Me

Hey! I'm Surya, a student developer at Newton School of Technology, ADYPU, Pune. I'm interested in building useful web applications and understanding how the pieces behind them work — from the user interface to server-side logic and databases. I learn best by working on practical projects, experimenting with code, debugging issues, and improving what I've built.

- 🌱 Currently strengthening my skills in JavaScript, Node.js, Express, and Python.
- 🎨 Comfortable working with HTML and CSS to build and style web pages.
- 🔧 Practising backend development, REST APIs, authentication, and database operations.
- 🗄️ Working with MongoDB and PostgreSQL while improving my SQL and data-modelling skills.
- 🚀 Interested in AI-powered applications, developer tools, and building projects that solve practical problems.
- 🤝 Open to learning with other developers, contributing to projects, and collaborating on beginner-friendly ideas.

I believe the best way to learn development is to build something, understand what went wrong, and keep improving it.

- Working on package structure and reusable functionality.
- Improving code quality, documentation, and developer experience.
- Learning what it takes to prepare and maintain an npm package.

### 🤖 PGRKAM AI — AI-enabled Web Project
Working on an AI-enabled web platform, with a focus on getting the AI integration working reliably and improving the site's features and overall experience.

### 🛡️ Email Fraud & Phishing Detection — Hackathon Idea
Exploring an AI-assisted approach to identifying suspicious emails and common phishing signals, such as:
- Lookalike and spoofed domains.
- Display-name spoofing and suspicious sender details.
- Hidden or misleading links.
- Business email compromise patterns.

*This is an idea/MVP direction I'm exploring, not a claim of a finished production system.*
